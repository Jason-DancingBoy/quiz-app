## 二、核心认知：面试官只需要「验证」，不需要「会写」

这是你最大的心理优势——**你不需要能写出 Agent，只需要能判断他说的对不对**。判断标准只有两类：

1. **「标准答案」类**：某个机制应该是什么样（背熟即可）→ 他答的和标准对得上 = 会；答不出 = 不会
2. **「真实性」类**：他说做过某个东西，你怎么验证 → 追问实现细节，讲得出细节 = 真做过；含糊 = 包装

所以你的学习目标是：**把面试手册第二节「简历核实总表」里每个技术点都理解到「能听懂他在说什么」的程度**。

## 三、知识地图（7 个模块，按优先级排序）

> 每个模块标注：为什么重要 → 核心概念 → 最少掌握 → 对应面试题 → 学习资源

### 模块 1：评测体系 RAGAS（🔴 最优先，面试第一题）

- **为什么**：Q1 是全场第一题，直接测诚实度，你握着代码答案
- **核心概念**：
  - Context Relevancy：检索到的上下文与问题的相关性（答非所问 = 低分）
  - Context Precision：检索结果中相关片段是否排前面（排序质量）
  - Faithfulness：回答是否忠于检索上下文（是否编造）
  - LLM-as-judge：用一个 LLM 当裁判评另一个 LLM 的输出
- **最少掌握**：三个指标各一句话定义（面试手册第六节已有）
- **对应面试题**：Q1
- **资源**：搜「RAGAS 指标 通俗解释」20 分钟扫完

### 模块 2：RAG 全链路（🔴 高优先）

- **为什么**：Quiz-App 核心，Q3/Q4 会考；你没有概念就听不懂他在说什么
- **核心概念**：
  - 切块（chunking）：文档按多大切、切太细/太粗的问题
  - Embedding：文字 → 高维向量，语义相近向量距离近
  - 向量库：ChromaDB（Quiz-App 用的）、sqlite-vec（Live-Edit 用的）
  - 检索：余弦相似度排序取 Top-K
  - 拼 prompt：检索结果 + 用户问题一起发给 LLM
- **最少掌握**：能把「文档进来 → 题目出来」的 6 步链路讲一遍（看一遍 quiz-app 的 `rag_service.py` + `generator.py` 就懂）
- **对应面试题**：Q3、Q4
- **资源**：**最佳教材就是你自己部署的 quiz-app 代码**——读 `backend/services/rag_service.py`（切块+检索）和 `generator.py`（生成），1 小时足够建立全貌

### 模块 3：Function Calling / 工具系统（🟡 中优先，你已有桥梁）

- **为什么**：Q9/Q11 会考；你有 MCP 经验，这里只需补「LLM 侧原理」
- **核心概念**：
  - 流程：声明工具 schema（函数名+参数）→ LLM 输出结构化 JSON（调哪个函数+参数）→ 程序执行 → 结果回填 → LLM 继续
  - schema 是给 LLM 看的「说明书」，描述质量决定 LLM 选工具准不准
  - 流式传输：LLM 分块返回，参数 JSON 是增量累积拼出来的
  - 错误分类：429（限流，读 Retry-After 头）/ 5xx（可重试）/ 4xx（参数错，不可重试）
- **最少掌握**：MCP 你已懂「工具定义→调用→回传」，只需补「LLM 怎么决定调哪个工具」（输出 JSON 而非直接执行）
- **对应面试题**：Q9、Q11
- **资源**：搜「Anthropic tool use 教程」或「Function Calling 原理图解」30 分钟

### 模块 4：Agent Loop 引擎（🟡 中优先）

- **为什么**：Live-Edit 核心，Q5/Q7/Q8 会考
- **核心概念**：
  - ReAct 循环：思考（reason）→ 行动（act，调工具）→ 观察（observe，看结果）→ 再思考
  - 三退出条件：max_rounds（最多转几轮）/ 无工具调用自动停 / 用户取消
  - nudge 机制：连续只读不写时主动引导「直接改」
  - 状态持久化：每轮保存对话历史，崩溃后能恢复
  - tool_use/tool_result 配对：Anthropic API 要求每个工具调用都要有结果回传，崩溃或被拒会产生「孤儿 tool_use」
- **最少掌握**：能用「思考→行动→观察→循环」描述 Agent 的一次任务流程
- **对应面试题**：Q5、Q7、Q8、Q10、Q12、Q13
- **资源**：读 Live-Edit 的 `engine.py`（有完整注释）+ 搜「ReAct agent 图解」

### 模块 5：记忆系统实现（🟡 中优先，从你的 Memory 经验升级）

- **为什么**：Q6 是 Live-Edit 重头戏；你懂「用记忆」，要补「实现记忆」
- **核心概念**：
  - 短时记忆（对话上下文）：超窗截断 + LLM 增量摘要（三档策略）
  - 长时记忆（向量库）：把重要信息向量化存储，检索时按相似度取回
  - 加权公式：`final = 余弦相似度 × 时效衰减 + 命中频次加权`（时效衰减 `exp(-rate×days)`，命中次数封顶）
  - 分层降级：短时没信息 → 查长时 → 再降级到项目知识库
- **最少掌握**：能复述「短时摘要、长时向量化、三层降级」的架构一句话
- **对应面试题**：Q6a/Q6b/Q6c
- **资源**：读 Live-Edit 的 `memory.py`（注释完整）+ 你的 CodeBuddy Memory 经验对照理解

### 模块 6：工程失败模式（🟡 中，你有 C++ 底子）

- **为什么**：Q2/Q7 会考「上生产会挂在哪」，这是区分「demo 玩家」和「能干活」的题
- **核心概念**：
  - 限流：内存计数（重启清零）vs Redis/DB（跨进程）
  - 重试：指数退避、区分可重试/不可重试错误
  - 超时：asyncio.wait_for、任务取消
  - 死循环防护：max_rounds + token 预算
  - 成本控制：选模型、缓存、减少轮次
- **最少掌握**：能说出「Agent 上生产会挂的三个点」及其兜底
- **对应面试题**：Q2、Q11、Q16
- **资源**：你的 C++ 工程经验直接迁移，读一遍 Live-Edit `provider.py` + Quiz-App `quota.py` 即可

### 模块 7：框架生态（🟢 低优先，听懂即可）

- **为什么**：Q14（自研 vs 框架）是高级题，他答了你得能接话
- **核心概念**：LangGraph（Node/State/Graph）、MCP（你熟）、LangChain
- **最少掌握**：知道「框架 = 把 Agent 循环标准化的工具」，LangGraph 核心是图（节点+状态流转）
- **对应面试题**：Q14、Q15
- **资源**：搜「LangGraph 是什么」10 分钟

## 六、面试当天的「作弊小抄」（打印带上）

1. **RAGAS 三指标一句话**：Relevancy=相关性 / Precision=排序 / Faithfulness=忠于上下文
2. **加权公式**：`cosine × exp(-rate×days) + weight × min(hit,10)`
3. **三档摘要**：不动 → 只截断 → 截断+摘要
4. **tool_use 配对**：每个 tool_use 必须有 tool_result，否则 API 400
5. **三退出条件**：max_rounds / 无工具 / 用户取消
6. **安全注入**：`ls; rm -rf /` → startswith 白名单可绕过
7. **错误分类**：429(限流) 5xx(可重试) 4xx(不可重试)
8. **RAG 链路**：上传 → 切块 → Embedding → 向量库 → 检索 → 拼 prompt → LLM
9. **你的最终防线**：任何他说的技术点，追问一句「具体怎么实现的？举个例子？」——讲不出细节就是包装
